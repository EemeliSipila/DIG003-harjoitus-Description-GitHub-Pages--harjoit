Viikko 2 – GitHub Actions -analyysi

Tehtävänä oli rakentaa automaattinen analyysi, joka tunnistaa repositorion ohjelmointikielet ja etsii mahdollisia suunnittelumalleja koodista.

Mitä tein?

  • Tein analysis.sh-skriptin, joka tarkistaa tiedostopäätteitä ja etsii tunnettuja suunnittelumalleihin viittaavia sanoja.
  • Lisäsin GitHub Actions -työnkulun, joka käynnistyy aina push- ja pull request -tapahtumista.
  • Työnkulku näyttää raportin lokissa ja tallentaa sen analysis-report-artefaktiksi.

Tulos

GitHub Actions: onnistunut

Analysoidussa harjoitusprojektissa käytössä ovat HTML ja CSS. Skripti ei löytänyt ohjelmakoodista selkeitä merkkejä Singleton-, Factory Method-, Observer-, Decorator- tai Strategy-malleista. Tunnistus perustuu yksinkertaisiin hakusanoihin, joten se ei ole täydellinen.
